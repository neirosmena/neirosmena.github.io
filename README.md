# Нейросмена — сайт-каталог ИИ-агентов

Статический одностраничный сайт для продажи готовых ИИ-агентов бизнесу.
HTML + скомпилированный Tailwind CSS + чистый JavaScript. Для публикации
сборка не нужна, внешние CDN не используются.

## Структура

```
ai-store/
├── index.html              # главная страница: hero, каталог, этапы, FAQ, CTA
├── privacy.html            # политика обработки персональных данных
├── css/
│   ├── fonts-v2.css        # локальный @font-face (Manrope)
│   ├── styles-v2.css       # тема, компоненты, анимации, адаптив
│   ├── tailwind-base.css   # preflight Tailwind
│   └── tailwind-utilities.css  # утилиты Tailwind, найденные в HTML
├── assets/
│   └── fonts/              # woff2-файлы шрифтов и лицензии OFL
├── js/
│   └── main.js             # меню, анимации появления, модальное окно, форма
├── favicon.svg
├── cloudflare-worker.js    # прокси через Cloudflare, если Wi-Fi не пускает Netlify
├── netlify.toml            # заголовки безопасности и кеширования
├── robots.txt
└── README.md
```

### Шрифты и Tailwind

Шрифты и CSS лежат в проекте, поэтому страница не ждёт Google Fonts и
`cdn.tailwindcss.com`. Это заметно ускоряет загрузку, особенно в России.
Используется один шрифт Manrope; его файлы уменьшены до 14–16 КБ, чтобы
не упираться в лимиты нестабильных мобильных и домашних сетей.

Все нужные утилиты Tailwind уже собраны в `css/tailwind-utilities.css`.
Если добавляете в HTML **новые классы Tailwind**, CSS нужно пересобрать.
Правка текстов, цен и изображений пересборки не требует.

## Локальный просмотр

Откройте папку в терминале и запустите любой статический сервер:

```bash
cd ai-store
python -m http.server 8080
```

Затем откройте `http://localhost:8080`.

Подойдёт и расширение Live Server в VS Code, и команда `npx serve .`.
Если открыть `index.html` двойным щелчком, вёрстка тоже отобразится, но
отправка формы не сработает — для неё нужен Netlify.

## Публикация на Netlify

### Вариант 1 — перетащить папку (быстрее всего)

1. Зайдите на [app.netlify.com/drop](https://app.netlify.com/drop).
2. Перетащите **папку `ai-store`** целиком (не отдельный `index.html`).
3. Netlify выдаст бесплатный адрес вида `https://имя.netlify.app`.
4. Проверьте сайт и отправьте тестовую заявку.

### Вариант 2 — подключить Git-репозиторий

1. Загрузите проект в GitHub / GitLab.
2. В Netlify выберите **Add new site → Import an existing project**.
3. Укажите репозиторий и настройки:
   - **Base directory:** `ai-store` (если папка лежит в корне репозитория);
   - **Build command:** оставить пустым;
   - **Publish directory:** `.` (относительно base) или `ai-store`.
4. Нажмите **Deploy site**.

Файл `netlify.toml` уже содержит `publish = "."` и базовые заголовки
безопасности.

### Как обновить уже опубликованный сайт

1. Откройте сайт в Netlify → **Deploys**.
2. Если сайт загружен через Drop, перетащите обновлённую папку `ai-store`
   в область **Drag and drop your site folder here**.
3. Дождитесь статуса **Published** и обновите страницу с очисткой кеша
   (`Ctrl + F5`).
4. Если подключён Git — просто сделайте commit и push, Netlify
   пересоберёт сайт автоматически.

### Если сайт не открывается с домашнего Wi-Fi

Иногда провайдер или роутер перестаёт пускать на IP-адреса Netlify: сайт
открывается с мобильного интернета, но не открывается с Wi-Fi. В этом случае
можно поставить перед сайтом бесплатный прокси Cloudflare Worker — сайт
останется на Netlify, а открываться будет по адресу Cloudflare.

1. Зарегистрируйтесь на [dash.cloudflare.com](https://dash.cloudflare.com)
   (бесплатный план).
2. Откройте **Workers & Pages → Create → Worker**, назовите его, например,
   `neirosmena`, и нажмите **Deploy**.
3. Нажмите **Edit code**, удалите код-заготовку и вставьте содержимое файла
   [`cloudflare-worker.js`](cloudflare-worker.js).
4. Нажмите **Deploy**. Cloudflare выдаст адрес вида
   `https://neirosmena.ваш-аккаунт.workers.dev`.
5. Откройте этот адрес с Wi-Fi. Форма заявки продолжит отправлять данные
   в Netlify Forms, потому что Worker проксирует и POST-запросы.

Сайт на Netlify удалять нельзя — он остаётся источником страниц и формы.
Если появится свой домен, его можно привязать к Worker в разделе
**Settings → Domains & Routes**, и адрес станет красивым.

> Адрес `*.workers.dev` может быть недоступен у некоторых провайдеров.
> Если и он не открывается, остаётся VPN либо перенос сайта на другой хостинг
> (Cloudflare Pages, GitHub Pages, Vercel) с заменой формы.

## Перенос на GitHub Pages

Сейчас сайт можно бесплатно разместить на GitHub Pages. Пока форма заявки
не подключена, на GitHub Pages и на Netlify включается режим предпросмотра:
форма и кнопки заказа скрыты, вместо них показывается пометка «Приём заявок
скоро откроется». Когда форма будет готова, этот режим уберём.

1. Создайте на GitHub публичный репозиторий, например `ai-store`.
2. Загрузите в **корень репозитория** содержимое папки `ai-store`:
   `index.html`, `privacy.html`, папки `css`, `js`, `assets`, остальные файлы.
   Не загружайте саму папку `ai-store` как вложенную — `index.html` должен
   лежать в корне репозитория.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите:
   - Source: **Deploy from a branch**;
   - Branch: **main** (или `master`), папка **/ (root)**.
5. Нажмите **Save** и подождите 1–2 минуты.
6. Сайт будет доступен по адресу:

```text
https://ВАШ-ЛОГИН.github.io/ai-store/
```

Проверьте его с домашнего Wi-Fi в приватном окне. Если открывается —
основная задача решена. Старая ссылка Netlify остаётся рабочей там, где
Netlify доступен; на домашнем Wi-Fi она по-прежнему не откроется.

> На GitHub Pages нет серверной части, поэтому форма заработает только после
> подключения внешнего сервиса (например, Web3Forms) или Cloudflare Worker.
> Сейчас на GitHub-версии форма намеренно скрыта.

## Форма заявок

Форма использует **Netlify Forms** — отдельный сервер и база данных не нужны.

- Имя формы: `ai-agent-order`.
- Поля: `agent`, `name`, `niche`, `telegram`.
- Скрытое поле `bot-field` — honeypot для защиты от спама.

После первого деплоя:

1. Откройте панель сайта в Netlify → **Forms**.
2. Убедитесь, что форма `ai-agent-order` появилась в списке.
3. Отправьте тестовую заявку на сайте.
4. Заявка появится в **Forms → ai-agent-order**.

На бесплатном тарифе Netlify доступно 100 отправок в месяц.

> При локальном просмотре отправка покажет экран ошибки — это ожидаемо:
> Netlify Forms работает только на опубликованном сайте. На Netlify форма
> отправляется в фоне, без перезагрузки страницы.

## Как менять контент

### Агенты и цены

Карточки находятся в `index.html` в секции `id="catalog"`. У каждой кнопки:

```html
<button class="btn btn-card js-order" type="button"
        data-agent="ИИ-Администратор 24/7"
        data-price="49 000 ₽ + 9 900 ₽/мес">
```

- `data-agent` — название, которое подставится в модальное окно и уйдёт в заявку;
- `data-price` — цена, которая показывается в модальном окне.

Цены в самой карточке меняются в блоках `.price-row` (внедрение и поддержка).
Чтобы добавить шестого агента, скопируйте любую карточку `<article class="agent-card ...">`
и поменяйте текст, иконку, задачи и `data-*` у кнопки.

### Бренд и контакты

- Название «Нейросмена» встречается в шапке, подвале, `<title>` и политике.
- Контакты не зашиты в код: все обращения приходят в Netlify Forms.
  При необходимости добавьте ссылку на Telegram или e-mail в подвал `index.html`.

### Цвета

Основные токены — в начале `css/styles-v2.css` в `:root`:

```css
--ink-950: #050b14;
--mint: #5eead4;
--sky: #38bdf8;
```

Меняйте их, чтобы перекрасить кнопки, акценты и фон.

### Тексты модального окна

Заголовки, подсказки и тексты успешной отправки — в `index.html`
(блок `#orderModal`) и в `js/main.js` (функция `openModal`).

## Что уже реализовано

- Адаптивная тёмная тема со стеклянными карточками и аккуратными анимациями.
- Каталог из 5 агентов: описание, задачи, цена, кнопка заказа.
- Модальное окно с подстановкой выбранного агента, валидацией имени,
  ниши и Telegram, экранами успеха и ошибки.
- Закрытие окна по Esc, клику по фону и кнопке; удержание фокуса внутри окна.
- Мобильное меню, плавные переходы, поддержка `prefers-reduced-motion`.
- FAQ на нативных `details/summary`, семантическая разметка, skip-link.
- Политика конфиденциальности и страница 404 не требуются: сайт одностраничный.
